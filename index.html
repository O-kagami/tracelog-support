Trace Log の使い方

歩いた道、立ち止まった場所、写真や曲を、一日のタイムラインで振り返るアプリです。アカウント登録は不要です。

お問い合わせへ

はじめて使うとき

  1. まずは「サンプルを見る」でタイムラインを試せます。個人の写真・音楽・位置情報への許可は不要です。
  2. 実際の移動を残すには「記録を開始」をタップし、位置情報へのアクセスを許可してください。終了するときは「記録を停止」をタップします。
  3. タイムラインの本文を右にスワイプすると前日、左にスワイプすると翌日に移動します。地図は記録の中で拡大できます。

よくある質問

ルートの線が途切れたり、移動手段が違って見えたりします。

別々の記録や長く位置を取得できなかった区間は、直線でつなぎません。滞在時間や徒歩・鉄道などの表示は推定です。地下や並行する線路と道路では実際と異なる場合があります。アプリを強制終了した場合は、次回起動時に記録を開始し直してください。

写真や曲が出てきません。

iPhone の「設定」で、Trace Log に許可した写真やミュージックライブラリの範囲を確認してください。「この日の写真を読み込む」で対象日の写真を反映できます。Apple Music の曲は記録中に検出できたものが対象で、過去の全再生履歴は読みません。Spotify の履歴は、解凍した拡張ストリーミング履歴の JSON を「設定」から選びます。

記録を消すには？

取り込んだ Spotify の履歴だけなら、アプリの「設定」→「読み込んだSpotify履歴を削除」を選べます。アプリ内の日記全体を消すには、iPhone で「Appを削除」を選んでください。「Appを取り除く」では書類とデータが残ります。元の写真や音楽、読み込み元のファイルは削除されません。

お問い合わせ

不具合やご要望は Trace Log のサポート窓口（GitHub Issues） へ。投稿には GitHub アカウントが必要です。

iOS のバージョン、操作した手順、期待した結果と実際の結果をお知らせください。投稿は公開されるため、氏名・連絡先・位置履歴・写真・音楽履歴の JSON・パスワードなどは書き込まないでください。
